# Contributing

Issues and small, focused pull requests are welcome. Please describe the Linux distribution, desktop session (X11 or XWayland), GTK version, and relevant error output when reporting a problem. Remove usernames, hostnames, and other private details from logs before sharing them.

Keep the widget local-only: do not add telemetry, credential collection, or network calls. Optional hardware metrics should fail gracefully when their driver or sensor is absent.
